# Visual identity direction

AIO3 should appear **futuristic, geometric, premium, and legible**. This is a working design system, not a finalized brand guideline.

## Marks and composition

The explored concept is an **AIO3 wordmark inside a hexagonal boundary**, with flattened geometry and subtly softened corners. Use a consistent clear-space rule, optically balanced lettering, and versions that remain legible at icon sizes. Do not stretch, rotate, or add gradients to the master mark.

## Working palette

| Token | Value | Intent |
| --- | --- | --- |
| Ink | `#171717` | Main text and strong surfaces |
| Graphite | `#262626` | Controls, key accents |
| Mid gray | `#737373` | Secondary information |
| Light canvas | `#FAFAFA` | Light backgrounds |
| White | `#FFFFFF` | Contrast and negative space |

Monochrome is the initial preference. Accent hues, if introduced, require accessibility testing and brand approval.

## Type hierarchy

- **Display:** geometric, modern, bold, with careful letter spacing.
- **Headings:** strong but clean, optimized for scanning.
- **Body:** readable sans-serif with generous line-height; prioritize clarity over ornament.
- **Code and labels:** consistent monospace where appropriate.

Select actual fonts only after checking licensing, multilingual support, page performance, and mobile rendering.

## Interface principles

1. Clear information architecture and predictable navigation.
2. High contrast, keyboard access, and visible focus states.
3. Restrained motion with reduced-motion support.
4. Real diagrams and project photos over generic AI stock imagery.
5. Accessible, responsive card layouts and concise labels.
6. Distinguish verified information from planned features.

## Current Mintlify implementation

The documentation theme is configured through `docs.json`. Existing logo assets are preserved as provisional until a reviewed AIO3 master asset set replaces them.

## Design QA

Check at mobile and desktop widths, zoom to 200%, keyboard navigation, contrast, screen-reader headings, dark-mode assets and alt text before launch.
