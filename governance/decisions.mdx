# Governance conventions

AIO3 documents should distinguish what is agreed, proposed, tested and validated.

## Status labels

- **Established direction:** a stated founding preference or documented setup.
- **Proposal:** a design option awaiting a decision.
- **Hypothesis:** a proposition requiring field evidence.
- **In pilot:** currently being tested against criteria.
- **Validated:** supported by relevant, repeatable evidence.
- **Deprecated:** superseded, with a replacement linked.

## Decision record template

```md
# Decision: [title]
Date:
Owner:
Status: Proposal | Accepted | Superseded
Context:
Options considered:
Evidence and limitations:
Decision:
Trade-offs:
Follow-up / review date:
```

## Review process

Changes affecting claims, child safety, pricing, consent, learner outcomes and brand identity require explicit owner approval. Write factual changes with sources and dates. Archive superseded pages rather than silently rewriting key decisions.
