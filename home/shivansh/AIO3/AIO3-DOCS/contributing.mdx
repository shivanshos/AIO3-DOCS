## Source of truth

This documentation is maintained in [shivanshos/AIO3-DOCS](https://github.com/shivanshos/AIO3-DOCS). The separate [AIO3-Core](https://github.com/shivanshos/AIO3-Core) repository hosts broader project work.

## Contribution workflow

1. Open an issue or discussion of the intended change.
2. Create a branch and edit the relevant MDX page.
3. Update `docs.json` navigation if you add or rename pages.
4. Preview with `mint dev` and check links, spelling, safety and sources.
5. Submit a pull request for review before merging.

Do not commit secrets, private learner information, copyrighted third-party course material, or unverified marketing claims.
