## Scope

The AIO3 lab introduces development environments, Linux, Git, containers, local inference, and later hardware-integrated projects. The objective is to understand systems, not just execute installation commands.

## Safety baseline

- Work on test machines or isolated user accounts.
- Keep backups before changing partitions, firmware, or system services.
- Never paste private API keys, tokens or passwords into public repositories.
- Confirm device and hardware compatibility before executing commands.
- Use adult supervision for younger learners, power tools, electronics, network changes and robotics.
- Make no changes to live or shared infrastructure without authorization.

## Suggested order

1. Terminal and filesystem basics
2. Git and source control
3. Python environment and package management
4. Networking and service concepts
5. Containers and local model serving
6. Observability, security, and reproducible experiments

Individual command walkthroughs should be added only after compatibility and safety review.
