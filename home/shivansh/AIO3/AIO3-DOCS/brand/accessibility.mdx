# Accessibility

Aim at least for WCAG AA across learning and administrative surfaces.

- Normal text contrast: minimum 4.5:1; large text: minimum 3:1.
- Focus states: clear 2px visible outline with offset, not colour alone.
- All important interactions must be keyboard reachable.
- Distinguish statuses using text/icons as well as colour.
- Form validation explains how to fix the error.
- Language changes include correct `lang` attributes; Devanagari uses appropriate fallback.
- Respect reduced motion and keep loading states comprehensible without animation.
- Never hide essential information in decorative glow, fine-line diagrams or colour-coded pathways alone.

**Specific check:** primary turquoise on paper is approximately 4.43:1, so it fails the 4.5:1 normal text threshold; use a dark semantic ink or verified alternate pairing.
