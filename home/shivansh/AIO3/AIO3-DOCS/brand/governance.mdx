# Asset governance

**Immutable master**: the original AIO3 monogram and wordmark vectors, locked palette, and source photography. Work from copies, preserving a traced original. Derived icons must not be mistaken for the canonical brandmark.

## Workflow
1. Record source file, creator, date, rights and intended usage.
2. Create on a branch or dedicated design exploration file.
3. Review legibility, brand fidelity, educational honesty and licensing.
4. Export for production (SVG or PNG), name deterministically, and document dimensions.
5. Validate on light/dark backgrounds and small-screen sizes.
6. Merge/publish only after review.

## Font release gate
Nebula needs commercial rights, and Nohemi/Helvetica Neue require EULA verification for seating and web embedding. Exclude font binaries and embedded copies by default. Never assume privacy equals licence.

## Naming
`aio3-{category}-{subject}-{variant}-{theme}-{size}.{ext}`, e.g. `aio3-background-nodefield-warm-dark-1920.png`. Do not rename canonical source files.
