### Composition
Use the **70 / 20 / 10** guidance: 70% paper/off-black surfaces, 20% turquoise family, and up to 10% warm or plum accents. This is a design composition guide, not a mandate for every UI state.

### Semantic colour
Keep semantic success, warning, error and info values distinct from the brand palette when needed, and document contrast for both themes. An accent colour alone must not encode success or failure.

### Contrast
Target WCAG AA: 4.5:1 for normal body text and 3:1 for large text and non-text UI boundaries. On dark surfaces, pair bright turquoise with off-black. Test primary action text against its actual fill rather than assuming turquoise is always accessible.

### Themes
- **Light:** `#FBFAF4` canvas, `#091717` text, True Turquoise action.
- **Dark:** `#091717` canvas, `#FBFAF4` text, Bright Turquoise highlights.
- **Warm presentation:** optional restrained Apricot/Terra Cotta haze behind content.

Avoid unrelated neon, saturated cyberpunk gradients and high-gloss 3D.
