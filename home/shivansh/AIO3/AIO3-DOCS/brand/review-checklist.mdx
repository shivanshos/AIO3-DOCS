---
title: "Brand Review Checklist"
description: "Pre-publication checks for any AIO3 asset, page, campaign or interface."
---

Run this checklist before anything carrying the AIO3 brand is published. An unchecked item blocks release.

## Identity

- [ ] Name written as **AIO3** (uppercase)
- [ ] Logo is an unmodified master SVG or a recorded derivative export
- [ ] Correct variant for the background (light, dark or mono)
- [ ] Clear space at least the cap height of the "A"
- [ ] No stretching, perspective, bevels, glows on letterforms or off-palette colour
- [ ] A3 icon used at small sizes instead of the full wordmark

## Colour and type

- [ ] Only locked palette values, within roughly 70 / 20 / 10 composition
- [ ] Typography roles respected (Nebula display, Nohemi headings, Helvetica Neue body, Sarpanch Devanagari, JetBrains Mono code)
- [ ] Fonts licensed for this use, or fallbacks used

## Accessibility

- [ ] Body text contrast at least 4.5:1; large text and UI boundaries at least 3:1
- [ ] True Turquoise not used for small text on Paper White (about 4.43:1)
- [ ] Visible focus states; keyboard reachable
- [ ] Status not conveyed by colour alone
- [ ] Reduced-motion respected
- [ ] Alt text written; correct `lang` attributes for Hindi

## Imagery

- [ ] No pseudo-text, fake data, fake interfaces or invented facilities
- [ ] AI-generated images labelled in the catalogue
- [ ] Guardian consent for identifiable minors
- [ ] No robots, brains, neon, cyberpunk or generic stock clichés
- [ ] Crops tested for 16:9, 4:5, 9:16 and 1:1 as needed

## Messaging

- [ ] No guarantees of jobs, income, admissions or outcomes
- [ ] No fabricated testimonials, partners or accreditations
- [ ] Hypotheses and pilots labelled as such
- [ ] Indian-language copy proofread by a native reviewer

## Provenance

- [ ] Source, creator, date and rights recorded
- [ ] Manifest row complete (see [Brand assets](/brand/assets))
- [ ] Named approval and date
- [ ] Deterministic export filename
- [ ] Previewed on light, dark and small screens
