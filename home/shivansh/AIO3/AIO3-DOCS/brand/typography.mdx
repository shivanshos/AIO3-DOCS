## Hierarchy

| Use | Typeface | Notes |
|---|---|---|
| Hero H1 and logo lettering | **Nebula** | Display only; original logo remains SVG outlines |
| Section headings, cards and buttons | **Nohemi** | Regular, Medium, SemiBold, Bold |
| Body, navigation and forms | **Helvetica Neue** | Roman, Medium, Bold |
| Hindi and other Devanagari | **Sarpanch** | Keep language and accessibility semantics |
| Code, commands and engineering data | **JetBrains Mono** | Berkeley Mono only if properly licensed |

### Typographic character
Large, confident headings; calm compact UI; readable learning materials. Avoid excessive tracked-out display copy, faux italics or mixing display type in paragraphs.

### Suggested scale
Use H1 48–72 px on desktop hero compositions, H2 32–40 px, H3 22–28 px, body 16–18 px, helper text 13–14 px. On mobile, fluidly reduce display sizes while maintaining readable body copy.

### Licensing and web delivery
<Warning>Do not assume a private repository permits commercial use, internal redistribution or public web embedding. **Nebula** was supplied as personal-use-only; commercial use requires appropriate rights. Confirm **Nohemi** and **Helvetica Neue** EULAs and seat/webfont terms before deployment. Keep binary files out of Git and public builds until approved.</Warning>

Use fallback font stacks when licences are unresolved; never replace the master logo SVG with fallback text.
