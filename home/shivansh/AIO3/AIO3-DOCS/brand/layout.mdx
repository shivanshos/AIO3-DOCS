# Layout and geometry

The existing radii remain: `0 / 4 / 8 / 12 / 16 / 24 / pill`. Apply 8px to controls, 16px to content cards, 24px to hero surfaces and pills to chips. Don't round every corner.

Build on a 4px spacing unit with generous editorial margins and balanced grid rhythm. Keep critical content calm and readable on mobile.

## Iconography
24 icons in outline and duotone families, built on a 32px grid with a 2px rounded stroke. Use meaningfully; never substitute unrelated generic icons for the approved A3 brand symbol.

## Graphic motifs
Approved graphics include sparse dot fields, asterisk motifs, topographic contours, node networks and subtle radial teal/apricot illumination. Maintain low opacity, avoid distracting text areas, and use real diagrammatic meaning where possible.

## Elevation
Shadows range from 0 to 3; never exceed level 3. Subtle hover elevation is appropriate only for interactive surfaces.
