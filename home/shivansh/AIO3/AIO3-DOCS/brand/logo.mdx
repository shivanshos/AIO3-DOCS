## Master assets

Use the supplied vector AIO3 Nebula wordmark and A3 icon masters. Retain the approved minimal monochrome hexagon concept with slightly softened finishing as a distinct approved mark direction; do not conflate it with the A3 icon without an asset-level decision.

The original assets include solid, hollow, outline, dark, light, circle, mono, warm and maskable variants. These are **variants**, not invitations to redraw the letterforms.

### Rules

| Element | Requirement |
|---|---|
| Wordmark | Always spell **AIO3** in uppercase; use original SVG outlines |
| Logo clear space | At least the height of the wordmark letter A, unless a master lockup specifies more |
| Shape | Preserve the approved mark and intended hexagon boundaries |
| Mono application | Use pure one-colour approved vectors on print, labels and stamps |
| App icons | Use supplied maskable artwork where safe areas are specified |
| Minimum size | Validate legibility at target size; avoid fine-detail treatments at favicon scale |
| Dark surfaces | Use supplied dark-surface wordmark, not arbitrary inverted colours |

### Don't
Never ask a generative model to invent the AIO3 logo, substitute generic technology imagery, stretch the mark, add unapproved glows to its letterforms, or render lettering in a lookalike font.

### Asset provenance
Compare every exported variation against the untouched SVG master in `icons/svg/`. Record version, author, canvas, colour mode and approval status. Use raster outputs for distribution, never as the master.
