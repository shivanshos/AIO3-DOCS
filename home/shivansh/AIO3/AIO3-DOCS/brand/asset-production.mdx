## Current AIO3 creative direction

Preserve the original AIO3 Nebula-derived wordmark and A3 icon masters without redrawing. Use True Turquoise `#20808D`, Bright Turquoise `#20B8CD`, Off Black `#091717`, Inky Blue `#13343B` and Paper White `#FBFAF4` with the approved supporting palette. Favor deliberate white space, modular grids, fine contour lines, restrained glows and believable learner/mentor environments.

### Adobe → Figma → GitHub → Mintlify

1. Accept the Adobe library/brand invitations and audit each library's contents, masters, owners, licences and variants.
2. Classify original masters separately from derivative artwork and draft/generated content.
3. Build or import token-bound, reusable components in an agreed AIO3 Figma file; retain unmodified vector logo files.
4. Version approved distributable exports and provenance manifests in the private [AIO3-BRAND repository](https://github.com/shivanshos/AIO3-BRAND).
5. Publish reviewed design guidance here. Never expose private Adobe invitation URLs, proprietary fonts, or unreviewed AI generation artifacts.

The current audit, approved color reference and Figma preparation notes are maintained in AIO3-BRAND. This documentation is draft and is not yet a finalized or published asset catalogue.
