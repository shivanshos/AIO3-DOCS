# Logo and identity

**Always write the brand as AIO3**. Use the existing A3 monogram and vector-outline AIO3 wordmark from the project archive; generated lettering, substitutes, AI reconstructions and logo recolouring are **not** canonical.

## Logo anatomy

- **Primary:** AIO3 Nebula wordmark; a vector path is preferable to font-dependent rendering in exports.
- **Compact:** Existing A3 monogram for square icons, favicons, course badges and navigation.
- **Variants:** Solid, dark, light, hollow, outline, circle, monochrome, warm gradient, maskable; select according to purpose.
- **Clear space:** At least the original brand guideline's A-height surrounding the wordmark. Never crowd the hexagon/monogram boundary.
- **Minimum sizes:** Validate legibility at 16, 24, 32, 64 and 180 px; use monogram rather than full wordmark at tiny sizes.

## Prohibited

Do not redraw letters with generative AI, distort aspect ratio, add metallic bevels, apply neon reflections, use non-palette accent colours, or place over high-contrast image detail.

## Production process

Use Adobe/Firefly for **background imagery only**. Use Figma/Illustrator/Express to composite the approved **original SVG mark** above generated assets. Publish exported SVG/PNG only from that approved vector master.

## Asset locations

Canonical source package includes `icons/svg/`, `icons/png/`, `icons/web/` and `docs/logo/` in the uploaded archive. Check redistribution and typography licences before public distribution.
