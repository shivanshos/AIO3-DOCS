# Colour and theme foundations

The original brand palette remains unchanged. Use these values exactly.

| Role | Token | Hex |
|---|---|---|
| Deepest dark | Off Black | `#091717` |
| Deep surface | Inky Blue | `#13343B` |
| Secondary deep | Peacock | `#2E565D` |
| Primary accent | True Turquoise | `#20808D` |
| Dark-mode accent | Bright Turquoise | `#20B8CD` |
| Light aqua | Sky | `#BADFDE` |
| Main light | Paper White | `#FBFAF4` |
| Muted light | Ecru | `#E5E3D4` |
| Warm highlight | Apricot | `#FFD2A6` |
| Warm contrast | Terra Cotta | `#A94B30` |
| Rare expressive accent | Boysenberry | `#954456` |

## Proportions

Use roughly **70%** background/base surface, **20%** turquoise family, **10%** selective warm accents. Never force accents into every component.

## Theme pairings

- **Light:** Paper White canvas, Inky Blue body text, True Turquoise highlights, Ecru muted surfaces.
- **Dark:** Off Black canvas, Sky/near-white text, Bright Turquoise highlights, Inky Blue panels.
- **Warm editorial:** Paper White with restrained Apricot and Terra Cotta for campaign moments.

## Accessibility

Check actual foreground/background text contrast. Aim for WCAG AA: 4.5:1 for normal text and 3:1 for large text and essential visual controls. Primary turquoise may not be contrast-safe as small text on every light surface; choose darker text where required. Never rely on colour alone to communicate state.
