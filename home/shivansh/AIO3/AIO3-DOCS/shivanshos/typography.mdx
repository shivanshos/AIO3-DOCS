# Technical clarity. Human rhythm.

Use IBM Plex Sans 400 and 600 for interfaces and documents. Use IBM Plex Mono for labels and technical data. The identity wordmark is fixed outlined artwork, not a display font for arbitrary headings.

## Hierarchy - implementation proposal

Display 64/68 px desktop and 40/44 px mobile; section heading 40/44 and 30/36; subsection 24/30; body 16/25; technical label 12/18. This scale is a new implementation proposal, not an inherited approved specification.

## Labels

Use IBM Plex Mono, uppercase and 0.12em tracking for short labels. Keep body paragraphs in sentence case. Avoid long uppercase passages, cramped line heights and tiny metadata.

## Composition

Keep paragraph measures near 55–75 characters where practical. Use weight, spacing and structure before adding color. Retain meaningful heading order across web and documents.

## Font provenance

This delivery bundles IBM Plex fonts from the official IBM repository with its OFL license. Nebula 2 is not bundled. The supplied kit records a personal-use notice for the wordmark source; commercial rights remain unresolved.
