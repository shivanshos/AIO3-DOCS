# A system of calm frames.

Build compositions with generous negative space, a clear reading order and a small number of strong visual anchors. Rounded rectangles echo the seal without turning every surface into a logo.

## Grid - implementation proposal

Use a 12-column desktop grid and a single-column mobile flow. Start with a 4 px spacing unit, 24–32 px gutters and a content maximum around 1280 px. These are practical extensions for this showcase.

## Surfaces

Use Paper for reading and Ink for identity display. Charcoal is a raised dark surface. The FINAL tokens specify a 16 px card radius. Avoid excessive borders, nested cards and unrelated decorative shapes.

## Image placement

Use complete application boards with captions and preserve their aspect ratios. Crop editorial images only when the focal subject remains intact. Never crop away a required logo clear-space region.

## Information order

Lead with the purpose, then the usable asset or rule, then provenance. Put download format and usage status next to each asset so the user can make a decision before downloading.
