# The right mark for the job.

The FINAL kit supplies a seal, an OS mark, mixed-case and uppercase wordmarks, and horizontal lockups. These are separate roles in one identity system. Use the original outlined artwork.

## Seal

S enclosed by the rounded-square O. Use for app icons, favicons and avatars. The kit specifies 24 px minimum width; its 16 px favicon is a test asset requiring visual validation.

## Mark

The OS presentation is suited to signage, stickers and covers. Minimum width in the kit: 56 px. Do not substitute it for the seal when a small square icon is needed.

## Wordmarks

ShivanshOS mixed-case is the working primary. The uppercase variant has a tightened V–A gap for nameplates and hardware. Minimum width: 120 px. Never retype either artwork.

## Horizontal lockup

Use for headers and presentation covers at 180 px minimum width. Use ink artwork on Paper and ivory artwork on Ink. Do not add a separate seal beside an existing mark lockup.
