# Say what is true.

The voice is precise, calm and useful. Write for someone deciding what to do next. Distinguish a concept, an available capability, a completed action and a verified result.

## Preferred vocabulary

Use create, research, build, connect, inspect, review and explore when they describe the action. Explain specialist terms when the audience needs them. Use the exact product or asset name consistently.

## Example: concept

Prefer “A concept for a shared project workspace” over “Your entire organization, fully automated.” The former describes the supplied work without inventing deployment or business outcomes.

## Example: status

Prefer “Prepared for review; commercial wordmark rights unresolved” over “Production-ready and approved.” State the remaining decision directly.

## Interface copy

Use “Download SVG”, “Copy HEX” and “View guidelines”. Confirm the actual result of an action. If copying fails, leave the value selectable and explain that it can be copied manually.
