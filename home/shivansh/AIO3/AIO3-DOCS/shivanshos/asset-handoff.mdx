# Original masters. Traceable exports.

Start with 01_Final_Identity for current artwork, 02_Final_Components for badges and nameplates, and 03_Final_Applications for concept layouts. Older explorations remain evidence of the design process.

## Format selection

Use SVG for scalable identity artwork and PNG when a platform requires raster. Retain transparency where appropriate. For app icons, choose an explicitly exported size rather than enlarging a tiny favicon.

## Editable sources

Application HTML files are supplied source layouts, not native Adobe Express or Figma templates. Some nameplate taglines remain live text; the source README identifies PNGs as appearance references.

## Manifest

This delivery includes an asset manifest containing relative paths, byte counts and SHA-256 hashes for current assets. Compare hashes before replacing a master and record the reason for any changed export.

## Naming and status

Keep meaningful original filenames and dark/light variants. Mark assets as current direction, concept or archive. “FINAL” in the folder name identifies source priority, not evidence of legal clearance or owner signoff.
