## Learning architecture

Each module should specify prerequisite skills, key concepts, guided demonstrations, independent practice, evidence of learning, and a reflection or presentation.

| Domain | Fundamental outcome | Sample evidence |
| --- | --- | --- |
| Computational thinking | Explain sequences, decisions and loops | A functioning small program |
| Development environments | Navigate files and tools safely | A reproducible working environment |
| Programming & data | Write and inspect small programs | A tested mini-project |
| Infrastructure | Explain services, networks and containers | A documented local lab |
| AI literacy | Distinguish capabilities and limitations | A model evaluation log |
| Physical computing | Connect software to physical sensors | A supervised prototype |
| Agentic workflows | Understand tools, permissions and review | An auditable limited-scope workflow |

## Assessment philosophy

Evaluate explanation, experimentation, iteration, responsible practice, and the final artifact rather than relying on quiz scores alone.
