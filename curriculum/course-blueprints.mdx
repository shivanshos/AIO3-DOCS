# Proposed courses

These are **design concepts**, not open enrollment products. Durations, age bands, pricing, equipment, mentors, and certifications are unconfirmed.

## 1. Computing explorers

**Focus:** logic, patterns, digital citizenship, and introductory STEM builds.

**Prerequisites:** age-appropriate reading and basic device familiarity, with accommodations as required.

**Project example:** explain and build a simple rule-based interactive activity.

**Learning evidence:** identify input, process, output, and a debugging change.

## 2. Python and maker foundations

**Focus:** variables, control flow, debugging, Git basics, and sensor concepts.

**Prerequisites:** foundational computational thinking and appropriate device access.

**Project example:** build a small data-collection or interactive Python project.

**Learning evidence:** demonstrate tests, explain choices and write reproducible instructions.

## 3. Linux and developer environment lab

**Focus:** filesystem, shell, processes, permissions, packages, virtual environments, and version control.

**Prerequisites:** comfort with typed commands and backup/safety guidance.

**Project example:** configure a non-production Ubuntu lab and document an application setup.

**Learning evidence:** explain commands, troubleshoot errors and recover from mistakes safely.

## 4. Containers, networking and services

**Focus:** IP addressing, ports, service lifecycle, Docker images, containers, volumes and deployment safety.

**Prerequisites:** Linux command line and basic programming.

**Project example:** deploy a simple local application with persistent data in a sandbox.

**Learning evidence:** diagram the architecture, inspect logs and explain isolation limits.

## 5. Applied AI and local models

**Focus:** tokens, inference, prompts, evaluation, model limitations, local serving and data privacy.

**Prerequisites:** computing foundations and basic APIs.

**Project example:** compare local-model outputs on defined tasks and document error patterns.

**Learning evidence:** evaluation rubric, limitations log and privacy review.

## 6. Responsible agents and automation

**Focus:** workflow planning, tools, permissions, state, human review and audit trails.

**Prerequisites:** programming, APIs and model evaluation.

**Project example:** build a limited-scope assistant operating on mock data.

**Learning evidence:** permissions diagram, test cases and human approval checkpoints.

## 7. Robotics, drones and sensor systems

**Focus:** circuits, sensors, control logic, feedback, simulation and physical-system safety.

**Prerequisites:** hardware readiness and supervised laboratory access.

**Project example:** simulate navigation or build a stationary sensor prototype.

**Learning evidence:** safety checklist, system diagram and test log. Real flight activities require applicable rules, qualified supervision and venue approval.

## Design rule

For every course, create a module specification with target readiness, prerequisites, learning objectives, sequence, workload, equipment, safety, assessment, inclusion accommodations, and pilot outcome metrics.
